# CLI UI Implementation Plan

**Goal:** Plan tables with plugin and theme versions, byte progress bars, and JSON manifests and result files for agents.
**Spec:** `docs/superpowers/specs/2026-09-22-cli-ui-design.md`
**Execution:** inline in this session (the user asked for speed). TDD on the pure parts. The integration suite runs before the PR.

## Global Constraints
- PHP 7.4 syntax only. No new dependencies.
- The plan output must still contain `CONFLICTS` and `scope: <label>` (the integration suite greps for them).
- Remotes older than 0.5.0 keep working: versions show `?`, and bytes are `null`.
- Version 0.5.0 in both the header and `IXES_VERSION`.

## Tasks

1. **Inventory.** `IXES_Transfer::inventory()` returns `{plugins, themes, stylesheet}` and is exposed in `/info`. `file_manifest()` returns `sizes` when asked. `IXES_Client::send_file` and `fetch_file` take an optional `$on_bytes`.
2. **Report.** `includes/class-ixes-report.php`, with the pure functions `build( array $in )`, `render_text( array $report )` and a small `table()`. `tests/ReportTest.php` covers the cases the spec lists.
3. **Adapters.** `IXES_Report::from_push_plan( $plan, $env, $info, $kind )` and `from_pull_plan( $plan, $env )` gather the inputs (local inventory, remote inventory, sizes, active lists) and call `build`. `save()` writes the latest and timestamped copies.
4. **Progress.** `includes/class-ixes-progress.php`, wired into `IXES_Applier::apply` and `IXES_Pull::run` in place of the per-file `$log`. `tests/ProgressTest.php` covers piped mode.
5. **CLI.** `diff`, `push` and `pull` render the report, take `--format=json` (with `--json` as an alias on diff), print the manifest path, and write `runs/<kind>-<env>-latest.json`.
6. **Docs.** The README gets a plan-output example, and the agent skill gets a "Files agents read" section that replaces `diff --json`.
7. **Version and checks.** Bump to 0.5.0. Run phpunit, phpcs, then the integration suite (assert the manifest and result files exist). Then the PR.
